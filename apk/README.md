# 📦 Fichier APK - JARVIS AI Assistant

Ce dossier contient le package d'installation Android (.APK) complet et fonctionnel pour l'application **JARVIS**.

## 📱 Détails du Fichier
- **Nom du fichier :** `jarvis-ai-assistant.apk`
- **Taille :** ~25 Mo
- **Architecture :** Android universel (SDK 26+ à SDK 35)
- **Version :** 1.0 Debug Build

## 🚀 Comment installer l'application sur votre téléphone Android :
1. Téléchargez ou copiez le fichier `apk/jarvis-ai-assistant.apk` sur votre appareil Android.
2. Ouvrez le gestionnaire de fichiers de votre téléphone et cliquez sur `jarvis-ai-assistant.apk`.
3. Si Android vous demande d'autoriser l'installation d'applications issues de sources inconnues pour cette application / ce navigateur, acceptez.
4. Cliquez sur **Installer**, puis lancez **JARVIS** !
